    Catalogue — Jeux & catégories¶

    Catégories¶

    GET /api/categories — Public¶

    Liste des catégories (API Platform).

    Réponse (collection JSON) — champs typiques :

    Champ Type
    id int
    name string
    slug string (si présent)

    Création / modification / suppression : admin uniquement (POST/PUT/DELETE protégés).

    Jeux¶

    GET /api/games — Public¶

    Liste des jeux visibles (extension Doctrine de visibilité : en pratique les jeux approved pour le public ; les devs voient aussi les leurs).

    Query params API Platform courants :

    Param Description
    page Pagination
    itemsPerPage Taille de page
    Filtres selon filtres ApiPlatform configurés (ex. category, status pour admin)

    GET /api/games/{id} — Public (si visible)¶

    Détail d’un jeu.

    Champs principaux (game:read)¶

    Champ Type Description
    id int
    title string
    description string
    price string (décimal) Prix de base
    isFree bool
    hasDemo bool
    playInBrowser bool Jouable dans le navigateur
    status string draft | pending | approved | rejected | suspended
    releaseDate datetime|null
    coverImage string|null URL ou chemin
    presentationImages array|null max 3
    presentationVideo string|null
    moderationNote string|null visible selon droits
    developer objet / IRI Profil développeur
    category objet / IRI

    POST /api/games — JWT développeur / admin¶

    Création (souvent en draft). Processor custom : GameCreateProcessor.

    Body (groupe game:write) : title, description, price, isFree, hasDemo, playInBrowser, category, coverImage, etc.

    PUT/PATCH /api/games/{id} — Propriétaire / modo / admin¶

    Mise à jour. Transitions de statut contrôlées (ex. dev : draft→pending, rejected→pending).

    DELETE /api/games/{id} — Propriétaire / admin¶

    Prix avec promotion¶

    GET /api/games/{id}/price — souvent public / JWT¶

    Retourne le prix effectif après promotions actives.

    Exemple de forme :

    {
  "game_id": 5,
  "base_price": "2500.00",
  "final_price": "2000.00",
  "currency": "XOF",
  "promotion": { "id": 1, "label": "...", "percent": 20 }
}

    (Exact shape : voir PromotionController / PromotionService.)

    GET /api/promotions/active — public¶

    Liste des promotions actives pour affichage boutique.
