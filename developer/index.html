Mes jeux

Méthode Endpoint Description
GET /api/developer/my-games Liste des jeux du développeur
POST /api/developer/games/{id}/resubmit Resoumettre après rejet
POST /api/developer/games/{id}/cover Upload couverture
POST /api/developer/games/{id}/presentation-images Upload images de présentation
DELETE /api/developer/games/{id} Supprimer mon jeu
POST /api/games Créer un jeu (API Platform, security developer)
PUT /api/games/{id} Modifier (si propriétaire / droits)

Cycle de vie : draft → pending → approved / rejected (→ éventuel resubmit) / suspended.

Création et mise à jour passent par des State Processors (GameCreateProcessor, GameUpdateProcessor) qui forcent le statut et le propriétaire côté serveur.

Versions & uploads (resumable)

Méthode Endpoint Description
GET/OPTIONS /api/developer/uploads/limits Limites (taille, types)
POST/OPTIONS /api/developer/uploads/init Initier un upload resumable
GET/OPTIONS /api/developer/uploads/{uuid} Statut de l’upload
PUT/POST/OPTIONS /api/developer/uploads/{uuid}/chunk Envoyer un chunk
POST/OPTIONS /api/developer/uploads/{uuid}/complete Finaliser l’upload

Utilisé pour les binaires de GameVersion (plateformes : android, ios, windows, web).

Endpoints API Platform GameVersion existent aussi pour le CRUD métadonnées (sécurité via voters).
