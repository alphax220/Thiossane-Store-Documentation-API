Interfaces de sécurité

Deux interfaces dans src/Entity/ gouvernent les ressources « privées » :

OwnableInterface

getOwner(): ?User — « cette ressource appartient à cet utilisateur ».

Utilisée par OwnershipVoter pour le droit de voir/modifier/supprimer cet élément.

ScopedToOwnerInterface extends OwnableInterface

+ getOwnerPath(): string — en plus, filtre la collection pour ne montrer que les ressources du user courant.

Utilisée par OwnershipCollectionExtension sur les GetCollection.

Exemple important : Review n’implémente que OwnableInterface (pas ScopedToOwnerInterface) car la liste des avis doit rester publique — seule l’édition/suppression est réservée à l’auteur ou à un admin.
