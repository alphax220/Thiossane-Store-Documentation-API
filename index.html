Thiossane Store — Documentation API

Mise à jour octobre 2026 — alignée sur le code backend actuel (src/Controller/Api/* + API Platform).

Cette documentation décrit tous les endpoints du backend dont un développeur frontend a besoin pour brancher l’interface (catalogue, compte, paiements, espace développeur, admin, support, notifications).

Stack backend

ÉlémentDétail

FormatJSON uniquement (Content-Type: application/json)

Rôles

RôleValeur APIAccès typique
UtilisateuruserCatalogue, achat, compte, favoris, avis, support
Développeurdeveloper+ publication de jeux, stats, uploads, ambassadeurs
Modérateurmoderator+ file de modération, signalements

Hiérarchie : ROLE_ADMIN ⊃ ROLE_MODERATOR / ROLE_DEVELOPER ⊃ ROLE_USER.

Paiements temporairement désactivés Les méthodes Wave, Orange Money et YAS sont désactivées côté backend ($allowedMethods = []). Les endpoints checkout existent encore mais rejettent toute méthode. Prévoir l’UI « bientôt disponible » côté front.
