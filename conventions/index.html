    Erreurs & conventions¶

    Codes HTTP utilisés¶

    Code Usage
    200 OK
    201 Création
    204 Succès sans corps
    400 Requête invalide / méthode non supportée
    401 Non authentifié / token expiré
    403 Authentifié mais non autorisé
    404 Ressource introuvable
    409 Conflit (email déjà pris, etc.)
    422 Validation métier / Symfony Validator
    429 Rate limit
    502 Erreur prestataire de paiement

    Corps d’erreur¶

    Forme la plus courante :

    { "message": "Description lisible" }

    Parfois :

    {
  "message": "Validation failed",
  "errors": ["champ X invalide", "..."]
}

    API Platform peut renvoyer le format Problem Details / hydra selon config ; ici le projet force souvent le JSON simple (formats: json).

    Auth¶

    • Header : Authorization: Bearer <jwt>
    • Ne pas envoyer le token sur les routes publiques si inutile
    • Sur 401 : tenter refresh une fois, sinon logout front

    Pagination (API Platform)¶

    Collections paginées : paramètres page, itemsPerPage.
    Réponse peut contenir hydra:member / member ou tableau direct selon la config de normalisation — tester GET /api/games sur votre environnement et s’aligner.

    Devise & montants¶

    • Devise boutique : XOF (Franc CFA)
    • Montants souvent en string décimale ("2500.00") pour éviter les erreurs float
    • Wave : pas de décimales pour XOF côté prestataire

    Téléphones (checkout)¶

    Format accepté : (?:\+221)?[0-9]{9}
    Exemples valides : 771234567, +221771234567

    Idempotence & doublons¶

    • Login invalide les anciens refresh tokens de l’utilisateur
    • Checkout crée order + payment ; ne pas spam-cliquer (rate limit)

    Fichiers & médias¶

    • Covers / images de présentation : URLs ou chemins renvoyés par l’API
    • Builds de jeux : via upload dev + liens signés de download
    • PDF commandes : GET /api/account/orders/export.pdf (JWT) → Content-Type: application/pdf

    Checklist d’intégration front¶

    1. Configurer API_BASE
    2. Implémenter login / register / refresh / logout
    3. Intercepteur 401 → refresh
    4. Catalogue public sans token
    5. Compte + favoris + ownership
    6. Checkout désactivé pour l’instant (message « bientôt »)
    7. Poll statut paiement quand réactivé
    8. Download via URL signée
    9. Espace dev (my-games, upload, reviews)
    10. Espace admin/modo selon rôle
