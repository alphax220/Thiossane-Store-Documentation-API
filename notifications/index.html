Notifications

Notifications in-app pour l’utilisateur connecté. JWT requis.

Méthode Endpoint Description
GET /api/notifications Liste des notifications (paginée selon query)
GET /api/notifications/unread-count Nombre de non lues
POST / PATCH /api/notifications/{id}/read Marquer une notification comme lue
POST /api/notifications/read-all Tout marquer comme lu

Chaque utilisateur ne voit que ses propres notifications.
