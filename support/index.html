Support

Tickets de support utilisateur et administration.

Catégories

Méthode Endpoint Auth Description
GET /api/support/categories Public / JWT Liste des catégories de tickets

---

Utilisateur

Méthode Endpoint Auth Description
POST /api/support/tickets JWT Créer un ticket
GET /api/support/tickets/mine JWT Mes tickets
GET /api/support/tickets/{id} JWT Détail d’un ticket (si propriétaire)
POST /api/support/tickets/{id}/reply JWT Répondre sur mon ticket

POST /api/support/tickets

{
  "category": "paiement",
  "subject": "Problème de paiement",
  "message": "Description du problème..."
}

POST /api/support/tickets/{id}/reply

{
  "message": "Suite de mon message..."
}

---

Admin

Méthode Endpoint Auth Description
GET /api/admin/support/tickets Admin Liste de tous les tickets
PATCH/POST /api/admin/support/tickets/{id} Admin Mettre à jour (statut, réponse staff)

Body typique de mise à jour admin :

{
  "status": "resolved",
  "reply": "Nous avons traité votre demande."
}

Les statuts exacts dépendent de l’implémentation du contrôleur SupportTicketController.
