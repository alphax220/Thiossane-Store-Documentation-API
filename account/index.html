Compte utilisateur

Préfixe : /api/account — JWT requis.

Vue d’ensemble

Méthode Endpoint Description
GET /api/account Profil enrichi
PATCH /api/account/profile MAJ username / email
POST /api/account/password Changer le mot de passe
POST /api/account/avatar Upload avatar (multipart)
DELETE /api/account/avatar Supprimer l’avatar
GET /api/account/orders Historique commandes
GET /api/account/orders/export.pdf Export PDF des commandes
GET /api/account/downloads Jeux téléchargeables (achetés / gratuits)
GET /api/account/favorites Liste favoris
POST /api/account/favorites Ajouter un favori
DELETE /api/account/favorites/{gameId} Retirer un favori
GET /api/account/favorites/{gameId}/status Est-ce un favori ?
DELETE /api/account Supprimer le compte

---

GET /api/account

Profil courant (plus riche que /api/me selon implémentation) : identité, rôles, avatar, statut, etc.

---

PATCH /api/account/profile

{
  "username": "nouveau_pseudo",
  "email": "nouveau@email.com"
}

Champs optionnels. Validations : username 3–180, email unique, etc.

L’avatar se gère via POST/DELETE /api/account/avatar (fichier), pas via une URL dans ce body.

---

POST /api/account/password

{
  "current_password": "...",
  "new_password": "..."
}

---

Avatar

POST /api/account/avatar

multipart/form-data avec un fichier image (champ selon implémentation, typiquement avatar ou file).

DELETE /api/account/avatar

Supprime l’avatar courant.

---

GET /api/account/orders

Liste des commandes de l’utilisateur (items, montants, statuts paiement).

GET /api/account/orders/export.pdf

Téléchargement PDF de l’historique.

GET /api/account/downloads

Jeux que l’utilisateur peut télécharger (après achat payé ou jeu gratuit).

---

Favoris

POST /api/account/favorites

{
  "game_id": 5
}

GET /api/account/favorites/{gameId}/status

{
  "favorited": true
}

DELETE /api/account/favorites/{gameId}

204 ou 200 selon implémentation.

---

DELETE /api/account

Suppression du compte utilisateur connecté (irréversible selon règles métier côté serveur).
