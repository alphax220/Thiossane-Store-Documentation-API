Administration & modération

JWT avec rôle admin ou moderator selon l’endpoint.

Utilisateurs & développeurs

Préfixe : /api/admin

Méthode Endpoint Rôle Description
GET /api/admin/users Admin Liste utilisateurs
POST /api/admin/users Admin Créer un utilisateur
PUT/PATCH /api/admin/users/{id}/status Admin active / suspended
PUT/PATCH /api/admin/users/{id}/role Admin Changer le rôle
GET /api/admin/developers Admin Liste développeurs
PUT/PATCH /api/admin/developers/{id}/verified Admin Marquer vérifié

Body status

{ "status": "suspended" }

Body role

{ "role": "developer" }

Valeurs : user \| developer \| moderator \| admin.

Modération des jeux

Préfixe : /api/admin/games

Méthode Endpoint Description
GET /api/admin/games/queue File de modération (pending, etc.)
GET /api/admin/games/{id} Détail + contexte modération
OPTIONS /api/admin/games/{id}/download CORS preflight download
GET /api/admin/games/{id}/download Télécharger le build pour revue
POST /api/admin/games/{id}/feedback Envoyer un feedback au développeur
POST /api/admin/games/{id}/approve Approuver
POST /api/admin/games/{id}/reject Rejeter (body raison optionnel)
DELETE /api/admin/games/{id} Supprimer
POST /api/admin/games/{id}/unpublish Dépublier
POST /api/admin/games/{id}/republish Republier

Les actions de modération génèrent des ModerationActivity (historique).
