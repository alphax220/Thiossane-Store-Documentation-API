Téléchargements & jeu navigateur

Propriété & téléchargement

Méthode Endpoint Auth Description
GET /api/games/{id}/ownership JWT L’utilisateur possède-t-il le jeu ?
GET /api/games/{id}/download JWT Génère un lien de téléchargement signé
GET /api/games/downloads/deliver Public* Délivre le fichier (token signé en query)

\* Public mais protégé par signature à durée limitée (DownloadLinkSigner).

GET /api/games/{id}/ownership

{
  "owned": true,
  "game_id": 5
}

GET /api/games/{id}/download

Prérequis : authentifié + (achat payé ou jeu gratuit) + version disponible.

Réponse typique :

{
  "download_url": "https://api.../api/games/downloads/deliver?token=...",
  "expires_at": "2026-09-22T13:00:00+00:00",
  "filename": "mon-jeu-v1.2.zip"
}

Le front ouvre download_url (ou le propose à l’utilisateur).

Jeu dans le navigateur (play)

Méthode Endpoint Auth Description
GET /api/games/{id}/play-info Public* Infos pour lancer le play (si playInBrowser)
GET /api/play-assets/... Public* Assets de jeu (chemins protégés / signés)
POST /api/browser-sessions/start JWT Démarre une session de jeu
POST /api/browser-sessions/{id}/heartbeat JWT Heartbeat (maintien session)
POST /api/browser-sessions/{id}/end JWT Termine la session
GET /api/developer/play-stats Dev Stats de play du développeur
GET /api/admin/play-stats Admin Stats globales

\* Accessible selon security.yaml ; le contenu peut rester restreint (démo / achat).

POST /api/browser-sessions/start

{
  "game_id": 5
}

Réponse : id de session, timestamps, etc.

POST /api/browser-sessions/{id}/heartbeat

Maintient la session active (évite l’expiration côté stats).

POST /api/browser-sessions/{id}/end

Clôture la session (durée de jeu pour les statistiques).
